# Project Supernova Dual-Goal Charter

## Goal 1 — verified reaction/cascade engine
Build a finite provenance-certified research engine in which executable mathematical operations and independently verified products create controlled sequential state transitions. Learned reaction structure may influence compute allocation only after independent verification. The finite cascade must prospectively beat ordinary/static/random controls on fresh mathematical obligations at the same complete resource cost.

Minimum claim: `S0 → R1 → S1 → R2 → … → Rk → Sk`. Depth, executable operators, verifier/checker authority, budget, cache/process rules, stopping conditions and complete-cost boundary are frozen before outcomes.

## Goal 2 — improvement of the improver
Separate solver/runtime `F_t`, retained mathematical/product memory `M_t`, and improvement machinery `I_t`. Compare `I_t(F*,B,M_control) → F_A` with `I_(t+1)(F*,B,M_control) → F_B` from the same untouched starting Foundry, matched complete R&D budget, same allowed model/tools/environment, controlled memory, frozen prospective tasks and independent evaluation. Better descendants, more memory, or merely repeating Goal 1 do not establish Goal 2.

Goal 2 opens only after Goal 1 passes. Its kill criterion is simple: if the apparent later-improver advantage disappears when starting solver, memory, development information and complete budget are held constant, classify it as solver accumulation, memory accumulation or uncontrolled carryover—not improvement of the improver.
